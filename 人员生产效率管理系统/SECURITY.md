# 安全说明

## 数据泄露

这是单机桌面应用，导出、模板、查询结果和明文 Excel 不受程序内加密保护。

请勿在 Issue、Pull Request、日志或公开仓库中提交：

- 员工姓名、工号、联系方式
- 客户、物料、供应商或生产数据
- 数据库文件、备份文件、授权文件
- 密钥、密码、解密工具或解密输出

## 密钥

源码中的演示密钥是公开的，不提供安全保护。部署真实环境前，应设置 `EMP_DATA_KEY`、`EMP_RENEWAL_KEY` 和 `EMP_LICENSE_EXPIRE_DATE`。

如果密钥曾进入 Git 历史，不要只删除最新文件；应停止使用该密钥并重新生成、迁移数据。

## 本地授权边界

授权和加密都在客户端执行。拥有本机控制权和逆向分析能力的人仍可能修改程序或提取运行所需密钥。高安全场景应使用服务器授权和服务端数据存储。

## 报告问题

发现安全问题时，请私密联系维护者，不要在公开 Issue 中粘贴真实员工数据、密钥或可复现的敏感数据。
